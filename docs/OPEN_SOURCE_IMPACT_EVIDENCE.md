# Seller Ops Desk impact evidence

This file describes the evidence needed for an honest open-source impact application. It is not a claim of current reach.

## Current verifiable artifacts

- Public repository: https://github.com/hamdirabahksu-maker/call-ledger-ai-boost
- Browser tool source: tools/seller-ops-desk/
- Reusable JavaScript package source: packages/seller-ops-core/
- Automated checks: GitHub Actions workflow for test and syntax check.
- License: MIT.
- Planned public demo: GitHub Pages workflow; it must be manually enabled and a successful deployment URL recorded before calling it live.
- npm package: publish workflow is prepared but the package is not yet published.

## Metrics to collect only after they exist

- Actual Seller Ops Desk demo visits or distinct users, with the measurement method and time period.
- Verified npm package version and monthly download counts from the public npm registry after publication.
- Actual GitHub stars, forks, issues, and external merged pull requests.
- Downstream packages or repositories that reference the published package, verified through public registry/GitHub evidence.
- Feedback from real sellers or independent developers using the tool, with permission to quote or identify them.

## Market survey distinction

The project founder has reported a one-month survey suggesting 65,800 businesses were interested in CallLedger. The underlying survey instrument, respondent/sample details, sampling method, and evidence are not included in this repository, so this number is not independently verified here. It describes reported market interest, not product users, conversions, downloads, open-source contributors, or downstream dependencies. Do not use it as evidence of actual open-source adoption unless the survey materials substantiate what was measured.

## Claude for Open Source application

Anthropic's discretionary Ecosystem Impact track asks for a project that the open-source ecosystem meaningfully depends on. A new public repository and a market survey alone do not establish that criterion. Apply only with current, accurate evidence and describe the project as early-stage until independent adoption is demonstrated.

Never purchase stars/downloads, use bots, exchange contributions, or create fake users/contributors. These practices can disqualify an application.
